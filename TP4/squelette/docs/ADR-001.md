# ADR-001 – Choix de PDO pour l'accès à MySQL

- **Titre** : Choix de PDO pour l'accès à MySQL.
- **Contexte** : l'application Gestion des stages doit communiquer avec MySQL/MariaDB.
- **Décision** : utiliser PDO avec le pilote pdo_mysql.
- **Conséquences** : gestion uniforme des erreurs par exceptions et requêtes préparées possibles.
- **Statut** : accepté.
