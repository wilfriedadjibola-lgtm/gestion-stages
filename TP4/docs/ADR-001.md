# ADR-001 – PHP natif + PDO, sans framework

- **Contexte** : projet de L3 en groupe, 1 h de prise en main, objectif pédagogique sur l'architecture en couches.
- **Décision** : PHP 8 natif, accès base via PDO (requêtes préparées), séparation Controllers / Services / Repositories.
- **Justification** : tout le monde comprend chaque ligne ; pas de dépendance à installer ; PDO protège contre l'injection SQL.
- **Conséquences** : routage et validation écrits à la main (plus de code, plus d'apprentissage) ; migration vers un framework possible plus tard.
- **Statut** : accepté – groupe, novembre 2026.
