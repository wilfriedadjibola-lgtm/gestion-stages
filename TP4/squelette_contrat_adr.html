TP4 – Squelette technique et contrat d'API

Projet : Gestion des stages – Projet informatique 2 · L3 SIL

Objectif

Mettre en place une première structure PHP, configurer l'accès MySQL avec PDO et définir les premiers points d'entrée de l'API.

1. Arborescence

Le dossier squelette contient public/, src/Controllers/, src/Services/, src/Repositories/, config/ et tests/.

2. Configuration et dépôt Git

config/.env.example présente les variables de connexion. Il faut le copier en .env sur chaque poste. Le fichier .gitignore exclut .env afin de ne pas publier les mots de passe.

3. Connexion PDO

La classe Database crée une connexion PDO MySQL avec PDO::ERRMODE_EXCEPTION, le jeu de caractères utf8mb4 et les requêtes préparées natives. Le test tests/test_connexion.php exécute SELECT 1.

4. Contrat des trois routes API

Méthode et cheminCorps / paramètresCodes de réponse
GET /api/santeAucun200 : base joignable ; 503 : base indisponible
GET /api/stagesAucun200 : liste vide au départ ; 500 : erreur serveur
POST /api/demandesJSON : etudiant_id, stage_id201 : créée (à implémenter) ; 400 : données invalides ; 500 : erreur serveur

5. Fiche ADR-001

Titre : Choix de PDO pour l'accès à MySQL.
Contexte : l'application Gestion des stages doit communiquer avec MySQL/MariaDB.
Décision : utiliser PDO avec le pilote pdo_mysql.
Conséquences : gestion uniforme des erreurs par exceptions et possibilité de requêtes préparées.
Statut : accepté.

Note : GET /api/stages et POST /api/demandes constituent le contrat initial. Leur traitement métier complet sera réalisé dans une prochaine étape. GET /api/sante est implémentée dans ce TP.
