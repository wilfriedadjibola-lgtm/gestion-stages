# PROJET INFORMATIQUE 2 — GESTION DES STAGES

**Licence 3 SIL — Année académique 2026–2027**

## Présentation
Application destinée à faciliter le suivi des demandes de stage entre les étudiants, les entreprises et les encadreurs.

## Objectifs
- Centraliser les informations des stages.
- Gérer les utilisateurs.
- Enregistrer et consulter les demandes.
- Suivre les validations et les refus.
- Sécuriser les accès.
- Assurer la traçabilité des opérations.

## Technologies
- PHP 8.4
- MySQL / MariaDB
- PDO
- HTML, CSS et JavaScript
- Git et GitHub
